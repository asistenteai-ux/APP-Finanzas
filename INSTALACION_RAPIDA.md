# ⚡ Instalación Rápida - 3 Pasos

## 📋 Requisitos Previos

Solo necesitas tener instalado **Node.js**:

1. Ve a: **https://nodejs.org/**
2. Descarga la versión **LTS** (recomendada)
3. Instala Node.js
4. **Reinicia tu computadora**

---

## 🚀 Instalación en 3 Pasos

### Paso 1: Descargar el código

Si tienes un archivo ZIP:
- Extrae todo el contenido
- Entra a la carpeta `APP-Finanzas`

### Paso 2: Ejecutar el instalador

1. Busca el archivo: **INSTALAR.bat**
2. Haz **doble clic** sobre él
3. Espera a que termine (3-5 minutos)
4. Cuando pregunte si quieres iniciar la app, escribe **S**

### Paso 3: ¡Listo!

La aplicación está corriendo en: **http://localhost:3000**

**Usuario admin:**
- Email: `admin@finanzas.cl`
- Password: `admin123`

---

## 🔄 Iniciar la aplicación después

Cada vez que quieras usar la app:

1. Haz doble clic en: **INICIAR_APP.bat**
2. Deja la ventana abierta mientras usas la app
3. Para detener, presiona **Ctrl+C**

---

## ❓ ¿Problemas?

Lee la guía completa: **GUIA_INSTALACION_WINDOWS.md**

O verifica que:
- ✅ Node.js está instalado
- ✅ Reiniciaste el PC después de instalar Node.js
- ✅ Ejecutaste **INSTALAR.bat**
- ✅ No cerraste la ventana negra mientras usas la app
